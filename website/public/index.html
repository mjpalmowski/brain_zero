A new Wi-Fi dongle
for Victron inverters.

Plug into your inverter’s VE.Bus RJ45 port.

No Cerbo, No Raspi, No MK3, No separate power supply needed.

  • Download & upload your MultiPlus-II settings file.
  • Adjust charging voltage from your phone.
  • Run ESS and schedules—even when Wi-Fi drops.

Native Home Assistant integration (optional).

Supports single inverter installations
Check your inverter and firmware ↓

The board comes with brain_zero software pre-installed. The firmware source lives in the GitHub repo. Download updates from GitHub Releases and install them over Wi-Fi from System → Firmware update.

Bundle includes the board, enclosure and a 15 cm RJ45 cable. Shipping across Europe included.

Inverter not supported? Submit your inverter data from inside brain_zero and we’ll work on adding support.

In the brain_zero web app, open System → Inverter settings → Submit to developer. Your controller reads a sanitized compatibility profile and submits it directly.

We aim to add support within 48 hours of receiving a valid profile.
